轻扫（Sweeply）技术支持

遇到问题或有建议，请在 GitHub Issues 中提交（需要免费的 GitHub 账号），通常会在 2 个工作日内回复。

为什么第一次打开要授权个人文件夹？

App Store 上的应用运行在沙盒里，只能访问你授权的位置。在弹出的选择框中直接点“授权”即可，只需一次。

清理掉的东西能找回来吗？

可以。轻扫只会把项目移到废纸篓，在 Finder 中打开废纸篓即可恢复。清倒废纸篓后才会真正释放空间。

为什么有些项目没有默认勾选？

系统组件、正在运行的应用的缓存，以及安装包、旧下载和大文件，需要你逐个确认，避免误删。

隐私政策

Sweeply Support

For questions or feedback, open an issue on GitHub Issues (a free GitHub account is required). We usually reply within 2 business days.

Why does Sweeply ask for access to my home folder?

Apps from the Mac App Store run in a sandbox and can only access locations you grant. Just click “Grant Access” in the panel — you only need to do it once.

Can I get cleaned items back?

Yes. Sweeply only moves items to the Trash. Open the Trash in Finder to restore them. Space is freed once you empty the Trash.

Why aren’t some items checked by default?

Caches of system components and running apps, as well as installers, old downloads and large files, need your review to avoid removing something you still need.
